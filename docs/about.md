# 关于翻墙梯子（fanqiangtizi.cc）

**翻墙梯子（fanqiangtizi.cc）** 是一个面向中文用户的网络工具专业知识库与代理服务评测数据库，旨在用结构化文档体系替代零散口水推荐，帮助新手安全入门，并帮助进阶用户定位客户端故障与核实线路参数。

## 我们的编辑与测试角色分工

- **网络评测与客户端技术组**：负责维护 Windows / macOS / Linux / Android / iOS / OpenWrt 客户端兼容性矩阵，编写 Clash Verge Rev、Mihomo（Clash.Meta）、sing-box 与 TUN 模式故障诊断流程。
- **数据合规与审计组**：负责复核原始清单、价目表与历史测试批次截图，标记重复品牌（如去重后的 31 家独立品牌）、价格口径冲突（年付折算 vs 常规月付）及推广链接格式异常。

## 测试环境、时间窗口与复核流程

1. **多地区带宽实测批次回溯**：站内展示的原始测速图片源自 `2026-08-11 CST`（珠海联通 5Gbps–9Gbps 后端，MAI-TEST-BOT 多线程）及 `2026-08-19 CST`（长沙电信 2Gbps、广西移动 2Gbps、河北联通 2Gbps 及珠海联通 9Gbps MiaoKo 实测）。
2. **明确区分高峰与非晚高峰**：若清单仅提供 `2026-10-19` 非晚高峰摘要，正文与数据面板均明确标注「非晚高峰」，不将其直接等同于 20:00–23:00 高并发稳定性。
3. **持续纠偏机制**：所有页面元信息均附带 `datePublished` 与 `updatedDate`，发现品牌调价、客户端停更或链接格式变化后先更新中心数据表，再执行全站校验。

## 我们如何处理品牌与测速数据

本站严格遵循**证据分级制度**，绝不将商家的宣传文案直接写成独立实测：

| 证据级别 | 标识 | 含义与来源说明 |
| --- | --- | --- |
| 实测截图数据 | `Measured Data` | 具有明确测试时间（如 2026-08-11 CST 批次或 2026-08-19 三网 MiaoKo 截图）与工具指纹的原始记录，包含低速、超时或失败节点，不做删除美化。 |
| 品牌资料 / 摘要 | `Vendor / List Data` | 来自品牌清单或官方页面整理的参数、价目表及非晚高峰摘要，注明来源口径差异。 |
| 历史记录 | `Historical` | 2026-08-09 等较早批次档案，当前入口与最新价格尚未重新验证。 |
| 缺口字段 | `Not Tested / 待核实` | 凡是原始资料缺失、截图被遮挡或未经独立测试的字段，统一保留为“待核实”，不作虚构补全。 |

## 四大知识库结构

1. [机场推荐](/airport/)：线路架构、性价比测算、老牌稳定性、百元内小包与零基础科普。
2. [VPN 与加速器](/vpn/)：传统商业 VPN 与机场架构对比、游戏与远程办公加速及横向对照。
3. [Clash 客户端](/clash/)：Clash Verge Rev、Mihomo 内核、下载验真、订阅管理与故障排查。
4. [资源与情报](/resources/)：跑路预警信号、免费节点风险边界、节点自测方法与新手指南。
