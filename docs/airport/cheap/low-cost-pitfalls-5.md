# 如何设置分流规则让 40GB–60GB 轻量低价套餐用满一整月

> **直接结论：** 对于只有 40GB–60GB 月流量的轻量年付套餐，只要守住“永不开全局模式 + 国内软件加直连 + 停掉自动云同步走代理”三条纪律，用满一整月绰绰有余。

## 让 50GB 小包发挥 200GB 效果的省流秘籍

1. **死守 Rule 规则分流模式**：禁止长期切为 Global（全局）。
2. **降低视频默认画质**：日常用手机或小窗看 YouTube 教程时，手动把画质设为 `720P` 或 `1080P`，比自动跑 `4K` 省下 **4–6 倍** 流量。
3. **屏蔽大体积后台更新**：在手机与电脑开启代理期间，不要在全局模式运行 Steam 更新、系统更新、OneDrive 大文件夹同步或网盘传输。
4. **开发依赖走国内源**：配置 npm、pip、Docker 国内镜像加速。
