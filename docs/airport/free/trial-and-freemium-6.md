# 学生党与开发者合法利用教育网资源与开源镜像减少梯子流量依赖

> **直接结论：** 合法利用高校教育网镜像与国内开源公共镜像站（清华 TUNA、中科大 USTC、阿里云等），能把 80% 以上动辄数 GB 的编程依赖与数据集下载流量留在本地直连，大幅延长轻量机场套餐的使用寿命。

## 开发者常用合法开源镜像加速设置

```bash
# npm 切换国内淘宝/阿里镜像源（开发拉包直连不扣梯子流量）
npm config set registry https://registry.npmmirror.com

# pip 切换清华开源镜像源
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

- 搭配 Clash **Rule（规则模式）**，访问国内镜像站会自动命中 `DIRECT` 直连规则，下载再多依赖包也不会消耗一丝海外代理流量。
