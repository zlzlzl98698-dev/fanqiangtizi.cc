# 什么是系统代理（System Proxy）与 TUN 虚拟网卡模式？何时需要开 TUN

> **直接结论：** 系统代理（System Proxy）工作在应用层，只接管浏览器等遵循系统设置的软件；TUN 模式则是创建一张虚拟网卡工作在网络层，能够强制接管终端命令行、游戏与全系统一切流量。

## 什么时候开“系统代理”，什么时候开“TUN 模式”？

- **90% 的日常场景（只开“系统代理”）**：刷 Chrome/Edge、用网页版 ChatGPT、看 YouTube 4K、看 Netflix，只开系统代理就够了，最省 CPU 电量且不与游戏加速器或 Docker 抢路由。
- **必须打开“TUN 模式”的 3 个场景**：
  1. 在 Windows PowerShell / CMD 里直接跑 `git clone`、`curl`、`pip`、`docker` 拉海外资源；
  2. 使用强制不读取系统代理的桌面软件（如部分 UWP 应用、Steam 客户端部分组件或外服联机客户端）；
  3. 需要全面接管设备底层 UDP/TCP 流量。
