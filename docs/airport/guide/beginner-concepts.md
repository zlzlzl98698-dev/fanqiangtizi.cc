# 科学上网零基础完全入门：5 分钟看懂机场、节点、订阅与客户端

> **直接结论：** 科学上网的日常运行只需要两个东西协同：**① 服务端（机场提供的节点与订阅链接）** + **② 客户端（你手机/电脑上的代理软件）**。专属客户端机场把两者打包成了一个 App；而通用订阅机场把“订阅链接”交给你，让你自由搭配 Clash Verge Rev 或 Shadowrocket。

## 一、四个高频核心名词 10 秒看懂

1. **机场（Provider）**：由于早期常见代理工具图标是小飞机（Shadowsocks），提供跨境中转服务器群的服务商就被中文互联网俗称为“机场”。
2. **节点（Node）**：机场部署在香港、日本、新加坡、美国等地的具体代理出口线路，一条订阅通常包含几十个节点。
3. **订阅链接（Subscription URL）**：一串专属的加密 HTTPS 网址。客户端通过这串网址就能一键把所有节点列表和剩余流量信息拉取到本地。**切勿泄露给陌生人！**
4. **代理模式（Rule vs Global vs Direct）**：
   - **Rule（规则模式，日常必选）**：自动识别国内网站（微信/淘宝/B站）直连不耗流量，只让海外域名走代理节点。
   - **Global（全局模式）**：所有流量强行绕一圈海外节点，访问国内变慢且浪费机场流量。
   - **Direct（直连模式）**：相当于临时关闭代理加速。

## 二、纯新手两条清晰起步路线

- **极简零配置路线**：选用提供自研客户端的品牌（如 [光速云](/brands/guangsuyun)、[飞猫云](/reviews/feimao)、[梯子云](/reviews/tiziyun)），下载官方安装包登录账号直接点连接。
- **进阶自由路线**：先读 [全平台客户端中心](/clients/) 安装 Clash Verge Rev 或小火箭，再导入通用订阅体验完整分流能力。

## 科学上网入门：下单核对与晚高峰实测指南

在阅读「科学上网零基础概念」专题集群时，围绕核心搜索意图（信息查询）需特别确认 科学上网 与具体落地环节是否匹配：帮纯新手 5 分钟弄懂机场、VPN、节点、订阅链接与客户端之间的协作关系。

1. **客户端模式匹配**：若需用 Clash Verge Rev、Shadowrocket 或 OpenWrt 软路由，下单前先核实上表中「客户端兼容」栏是否包含第三方订阅，避免误选仅限专属客户端的品牌。
2. **晚高峰真实验证**：收到订阅后不要只看白天测速数值，重点在 **20:30–22:30** 测试目标地区的单线程网页响应与 Cloudflare Speedtest 丢包率。
