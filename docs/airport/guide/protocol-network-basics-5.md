# 什么是机场的“审计规则”？为什么 BT 下载和某些邮件端口会被屏蔽

> **直接结论：** 机场“审计规则”是服务商为了防止服务器 IP 被海外运营商投诉封禁或遭受黑产滥用而设置的出口拦截清单——最常见的被屏蔽行为就是 BT/PT 下载、垃圾邮件群发端口（SMTP 25）及涉政违禁扫段。

## 机场普遍禁止哪些流量？

1. **BT / eMule / 迅雷等 P2P 版权下载**：海外机房一旦收到 DMCA 版权投诉邮件，整台服务器 IP 可能被上游商家直接拔线封停，因此所有正规机场均审计拦截 BT 协议。
2. **端口扫描与恶意发包**：禁止挂载 SSH 爆破或自动发信垃圾邮件端口。
3. **高风险违禁站点**：绝大多数服务在服务端内置基础合规审计名单，命中后直接丢弃请求并可能触发封号警告。
