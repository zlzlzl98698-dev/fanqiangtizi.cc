# 多设备家庭共享机场推荐标准：设备数限制与并发规则

> **直接结论：** 家庭多终端共享的核心在于“是否限制设备同时在线数”与“同网络出口 IP 判定规则”。选择明确标注不限设备且支持路由器或第三方订阅的机场，才能以一份订阅覆盖电脑、手机、平板与电视盒子。

## 一、设备数限制 vs 在线 IP 数限制

- **个人多端同网络**：在同一台家用路由器 Wi-Fi 下，手机、电脑、iPad 与 Apple TV 对外共享同一个宽带公网出口 IP，多数机场只计为 1 个接入点。
- **跨地域并发**：同时在公司电脑、家里软路由和外出 5G 手机使用，会产生多个独立来源 IP，此时必须挑选明确标注“不限设备”的品牌（如光速云、星岛梦、二猫云、唯兔云、U1S1、一翻云、灵猫网络）。

## 二、家庭共享推荐配置架构

1. **客厅统一代理**：选用支持 Clash/sing-box 通用订阅的品牌写入 [OpenWrt 软路由](/clients/openwrt)（OpenClash / HomeProxy），全屋电视与主机无需单独安装软件。
2. **外出单端接管**：手机安装 FlClash 或 Shadowrocket 仅在离开家庭 Wi-Fi 时开启。

## 不限设备机场：下单核对与晚高峰实测指南

在阅读「机场综合选型标准」专题集群时，围绕核心搜索意图（商业调研）需特别确认 机场推荐 与具体落地环节是否匹配：理解专线与中转差异、计费倍率、协议支持与实测数据核验方法。

1. **客户端模式匹配**：若需用 Clash Verge Rev、Shadowrocket 或 OpenWrt 软路由，下单前先核实上表中「客户端兼容」栏是否包含第三方订阅，避免误选仅限专属客户端的品牌。
2. **晚高峰真实验证**：收到订阅后不要只看白天测速数值，重点在 **20:30–22:30** 测试目标地区的单线程网页响应与 Cloudflare Speedtest 丢包率。
3. **AI 与流媒体分地区策略**：主流香港节点往往对网页版 ChatGPT 与 Gemini 存在地区限制，日常可在 Clash 中为 AI 域名单独指向新加坡、日本或美国节点。
