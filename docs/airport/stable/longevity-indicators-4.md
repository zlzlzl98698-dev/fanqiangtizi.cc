# 特殊时期（敏感节点期）机场断流怎么办？多入口容灾原理

> **直接结论：** 每年特殊网络管控时期，部分常用香港/日本热点入口 IP 可能出现间歇性波动；具备多地区节点与多入口协议的机场往往能通过切换新加坡、台湾或冷门欧美节点保持不断网。

## 特殊时期机场保活实用策略

1. **提前更新并保留全节点订阅**：平时不要只留 2 个香港节点而删掉其他地区。当香港专线局部抖动时，新加坡、台湾、日本与美国西海岸节点常扮演重要接替角色。
2. **多协议备份**：若 SS 协议入口临时受阻，切换同机场内的 VLESS-Reality 或 Trojan 节点常能立刻恢复。
3. **常备一个独立备用源**：如前所述，低成本百元永久包能消除单一服务商维护期的焦虑。
