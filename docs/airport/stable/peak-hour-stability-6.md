# 机场官网无法打开或订阅域名被屏蔽时的应急通道策略

> **直接结论：** 机场官网域名由于各种网络策略偶尔会无法从国内直连打开，但绝大多数情况下节点隧道本身依然正常工作。买完套餐后保存好防失联信息，就能防止“想续费却找不到门”的尴尬。

## 买完机场后必存的“保命三件套”

1. **官方防失联地址发布页（GitHub / 永久跳转域名）**：通常印在官网登录页最显眼位置或欢迎邮件中。
2. **订阅 URL 备用纯文本副本 + 可用客户端本地留档**：即便官网域名暂不可达，只要开启 Clash 里原有的任意节点勾选“使用代理”就能轻松打开最新官网。
3. **官方工单/客服联系方式（TG 频道或官方邮箱）**：避免在百度搜索假冒仿冒网站踩中钓鱼登录页。
