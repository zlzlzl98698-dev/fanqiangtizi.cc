# 晚高峰稳定性深度解析：为什么 20:00–23:00 容易断流以及如何应对

> **直接结论：** 应对晚高峰断流不能只靠换品牌，更要靠**三层配合**：① 选用具备 IEPL/BGP 冗余的线路；② 避开单线超售严重的超低价拥挤节点；③ 在客户端里把默认的 `select` 手动组配合 `fallback` 自动故障转移组使用。

## Clash Verge Rev 晚高峰自动容灾覆写示例

如果你希望当首选香港专线1号在晚高峰偶然卡顿时，客户端在 5 秒内自动切到新加坡或香港备用2号，可以在 Clash Verge Rev 的全局扩展配置中加入如下 `fallback` 逻辑：

```yaml
proxy-groups:
  - name: "晚高峰自动容灾"
    type: fallback
    url: "https://cp.cloudflare.com/generate_204"
    interval: 180
    tolerance: 80
    proxies:
      - 香港专线01
      - 香港专线02
      - 新加坡01
```

- **为什么用 `fallback` 而不是 `load-balance`**：负载均衡会把相邻请求随机打向不同国家 IP，导致登录银行、Cloudflare 或 ChatGPT 频繁触发异地风控验证码；`fallback` 平时始终锁定第一个节点，仅在它连续超时时才平滑切至顺位下一节点。
