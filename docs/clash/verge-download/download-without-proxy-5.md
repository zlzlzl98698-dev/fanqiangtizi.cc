# macOS 首次启动授权系统网络扩展与更改系统代理权限弹窗说明

> **直接结论：** macOS 系统对修改全局路由表与创建虚拟 TUN 网卡接口有非常严格的内核提权保护（Rootless / Network Extension），首次授予授权需要输入管理员密码属正常安全机制。

## 减少 Mac 反复弹窗输密码的正确方式

- **日常纯浏览器上网**：不启用 TUN 模式，仅使用普通“系统代理”，无需每次提权输密码。
- **经常使用 TUN 的用户**：可在 Clash Verge Rev 设置中正确安装 **Service Mode（服务模式）** 后台服务，由系统级守护服务统一接管权限，避免每次手点打开开关都要输入系统密码。
