# 全平台第三方代理客户端文档中心（2026）

**核心分类：** 代理软件主要分为**第三方开源通用客户端**（如 Clash Verge Rev、v2rayN、Shadowrocket、FlClash、Hiddify，可导入兼容订阅并自定义规则）与**机场专属客户端**（部分服务商仅支持账号登录，不提供订阅链接）。本中心重点梳理 6 大平台共计 **20 款可核实官方来源的第三方客户端**。

## 按操作系统进入对应指南

| 平台 | 主力推荐客户端 | 核心注意事项 | 专题入口 |
| --- | --- | --- | --- |
| **Windows 电脑** | Clash Verge Rev · v2rayN · FlClash | 区分 x64 / ARM64；已停更的 CFW 请尽快迁移 | [Windows 客户端指南](/clients/windows) |
| **Android 安卓** | v2rayNG · FlClash · Hiddify · Karing | 警惕 Google Play 第三方控制版 NekoBox，认准 GitHub | [Android 客户端指南](/clients/android) |
| **iPhone / iPad** | Shadowrocket · Stash · Karing · Streisand | 小火箭/Stash/圈X 需外区 Apple ID 且多为付费应用 | [iOS 客户端指南](/clients/ios) |
| **macOS 苹果电脑** | Clash Verge Rev · FlClash · Surge Mac | 区分 Intel (`x64`) 与 Apple Silicon (`arm64`) | [macOS 客户端指南](/clients/macos) |
| **Linux 桌面/主机** | Clash Verge Rev · FlClash · v2rayA | 按发行版区分 DEB / RPM / AppImage；无桌面选 v2rayA | [Linux 客户端指南](/clients/linux) |
| **OpenWrt 软路由** | OpenClash · PassWall2 · Nikki · HomeProxy | 核实系统版本（如 Nikki 要求 24.10+）与 CPU 架构 | [OpenWrt 软路由指南](/clients/openwrt) |
