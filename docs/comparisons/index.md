## 横向对比的四条硬性评测口径

为避免各品牌宣传页使用不同统计周期导致“田忌赛马”式的参数失真，本站所有对比专题均强制统一以下 4 项审计尺度：

1. **计费与流量倍率口径**：明确标出是否全节点 `1×`（1 倍）消耗，以及“年付折算均价”是否具备对应低容量限制（例如多款 ¥84–¥109/年的年付小包每月仅配给 `45GB–80GB` 流量，明显少于 ¥20–¥27 常规月付版的 `120GB–200GB`）。
2. **协议与客户端生态边界**：将仅限自研 APP 登录的“专属客户端机场”（如飞猫云、SOGO 云、闪跃、隐形人、全球云、灵猫网络、无忧链接新版）与开放通用订阅的“Clash / sing-box 兼容机场”（如光速云、微风网络、星岛梦、暮光加速、二猫云、一翻云）清晰区分，防止软路由和 Mac/iOS 小火箭用户买错无法导入。
3. **测试批次与非高峰边界**：注明 2026-08-11 截图包与 2026-08-19 三网 MiaoKo 实测图片的具体时间窗口；针对明确标出“非晚高峰”的清单摘要如实附带提示，不将白天极速直接等同于晚间 21:00 高并发稳定率。
4. **首单低风险试错逻辑**：对未经过连续多月复测的新晋品牌、缺乏测速图的品牌或标有链接格式预警的品牌（如云界线、环球梯及 2026-08-09 历史记录批次），全部提示先月付试水或改选证据链完整的主力服务。
