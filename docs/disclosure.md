# 商业合作与推广链接披露声明

为保障知识库的长期免费维护、实测数据归档与教程体系持续更新，**翻墙梯子（fanqiangtizi.cc）** 在部分品牌详情页、评测文章与横向对比表格中保留了服务商联盟计划提供的推广注册链接（Affiliate Links）。本站依据公开透明原则向所有访问者说明具体合作与利益披露边界。

## 四项核心披露准则

1. **不影响用户价格**：通过本站推广链接前往第三方服务商官网注册，**不会增加您的任何购买费用**；输入档案中记录的验证优惠码时反而可能享受对应首单折扣（具体折扣适用套餐以服务商结账页面实时显示为准）。
2. **统一技术收口与强制属性标注**：全站所有外部推广 URL 均集中托管在结构化链接库中，任何 Markdown 正文严禁硬编码推广域。前端渲染的所有出站推广按钮均强制附加 `target="_blank" rel="nofollow sponsored noopener"` 属性，同时对链接格式存在异常（如缺少 `#` 路由标识）或属于 `2026-08-09` 历史档案的入口额外展示风险微标（`格式待确认` / `历史待核实`）。
3. **优先展示位与实测边界严格分离**：部分商业合作方（例如 [光速云](/reviews/guangsuyun)）会在专题首页与精选卡片获得优先推荐展示，但优先推荐**绝不等于**篡改或隐藏不利测试样本。例如在光速云评测中，本站依然明确披露香港专线“OpenAI 仅 APP”、部分节点 Gemini 失败、特殊流量包不支持退款以及 59GB/69GB 历史口径冲突。
4. **首单低风险试错守则**：跨境代理服务普遍受地区宽带政策与国际出口拥堵影响，无论品牌是否处于合作优先位，本站始终反对新手首单直接购买不可退换的多年付大额方案，一律建议先选择月付或轻量小包亲自在晚高峰时段验证后再决定是否续费。
