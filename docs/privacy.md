# 隐私政策与使用声明

## 1. 纯静态文档架构与零个人数据采集

**翻墙梯子（fanqiangtizi.cc）** 是完全基于 VitePress 构建的纯静态 HTML/Markdown 知识库站点，无任何后端用户数据库或动态会话追踪：

- 本站不提供用户注册、登录、评论提交或在线支付结算功能，不会收集或存储访问者的姓名、手机号码、邮箱账号、支付凭证或真实网络身份信息。
- 本站未在页面中植入任何第三方广告联盟像素（如 AdSense）或跨站用户画像分析脚本；站内全文检索（Local Search）全部在访问者本地浏览器内存中离线运行。
- 本站不自行架设、分发或销售任何代理节点服务，也不提供任何代理软件可执行文件的本站网盘镜像或魔改二进制打包；所有客户端获取指南均明确指引访问原开发者 GitHub Releases 官方仓库或系统官方商店（如 App Store）并建议核对哈希值。

## 2. 第三方外部链接跳转声明

当您主动点击本站“前往官网注册”等外部链接离开 `fanqiangtizi.cc` 前往第三方服务商网站时，您在该外部站点上的注册信息提交、支付交易与网络安全行为将完全受对应服务商自身的隐私条款与服务协议管辖。安全操作建议：请始终为外部代理面板生成**独立随机密码**与专用别名邮箱，绝不将国内日常金融账户、支付密码或主力个人密码复用至任何外部站点；同时妥善保管包含个人身份验证 `token` 的订阅 URL。
