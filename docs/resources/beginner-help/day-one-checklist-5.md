# 买完后记得收藏的 3 个关键信息：防失联页、客服入口与账号凭据

> **直接结论：** 很多老手换新机场后的第一件事不是急着测速，而是打开浏览器把服务商的 **防失联发布页、客服工单联系方式与登录邮箱凭据** 放进安全备忘录里，确保就算有一天主域名打不开了也永远能找回账号。

## 买完机场立刻随手保存的 3 个关键信息

1. **官网防失联地址发布页**：通常在机场公告置顶或注册欢迎邮件最底行给出一个永久防迷路网址（或 GitHub 发布地址）。
2. **官方客服联系通道（邮箱 / 公告频道）**：防止百度搜出钓鱼高仿登录页。
3. **账号注册邮箱 + 独立密码（存进密码管理器）**：方便更换电脑时一键重新登录后台提取订阅链接。
