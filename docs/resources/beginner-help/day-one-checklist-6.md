# 第一次用外网必备基础工具书签：Google 搜索技巧、Chrome 安装与翻译插件

> **直接结论：** 第一次顺利连上外网面向更广阔的英文技术与信息世界时，配置好浏览器高效双语翻译插件、学会两个基本 Google 搜索限定指令，能让你的查阅效率瞬间翻几倍。

## 首次连接外网必备 3 件实用效率工具

1. **浏览器推荐**：桌面优先使用干净无流氓弹窗的 **Google Chrome** 或系统自带 **Microsoft Edge**（均支持完整扩展与原生翻译）。
2. **双语对照翻译插件**：如 **沉浸式翻译（Immersive Translate）** 或浏览器自带右键整页翻译，阅读 GitHub README、英文论文和海外技术文档时中英对照极为顺眼。
3. **两个实用 Google 搜索技巧**：
   - `site:github.com 关键词`（仅在 GitHub 站内精确搜索开源项目）
   - `"完整报错提示" solution`（带英文双引号精确匹配原始报错信息找原汁原味解法）。
