# 如何给家里的父母或非技术同事配置最不易出错的一键代理环境

> **直接结论：** 给不懂电脑的父母或非技术同事配置代理工具时，千万不要把需要学概念的开源软件和一大堆规则塞给他们——最不容易出错的是“硬件软路由全家直连”或“极简免配置专属端”。

## 最不易出错的 2 种“零维护”配置方案

1. **同一屋檐下（家里父母最强方案）→ 客厅软路由透明代理**：在客厅路由器部署好稳定可靠的 **OpenClash / HomeProxy** 与长效老牌机场年付订阅。父母手里的电视、iPad 和手机甚至不需要安装任何额外软件，连上家里 Wi-Fi 就能稳稳刷外网，永远不出错。
2. **不在同一个城市 → 选用双支持或专属一键端 + 固定桌面端**：帮对方电脑装好具备自研一键登录客户端的机场（如飞猫云、梯子云、光速云），或者配好 Clash Verge Rev 并锁死单节点、关闭一切自动弹窗更新提示。
