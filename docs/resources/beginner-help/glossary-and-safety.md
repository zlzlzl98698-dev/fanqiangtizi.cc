# 网络代理核心术语词典（新手速查版）与日常安全守则

> **直接结论：** 掌握下面 **8 个核心术语**，你就能看懂 99% 的机场价目表、测速截图与客户端面板提示，不再被营销黑话绕晕。

## 常用术语 1 分钟速查表

| 术语 / 缩写 | 真实含义与计算方式 | 新手实用提醒 |
| --- | --- | --- |
| **Mbps vs MB/s** | 差 **8 倍**：`8 Mbps = 1 MB/s` | 400Mbps 节点下载文件约 50MB/s，别误以为被限速 |
| **1× 倍率** | 流量消耗比例（实际 1GB = 扣费 1GB） | 优先选全节点 ×1 倍率套餐，小心高倍率节点暗中扣光流量 |
| **IEPL / IPLC** | 跨境内网专线（不走普通拥堵公网） | 晚高峰较稳，成本较高；看到 5 元全线 IEPL 需结合实测核验 |
| **VLESS / Trojan / Hy2** | 现代主流代理加密传输协议 | 需要搭配 Mihomo（Clash Verge Rev/FlClash）等新版客户端 |
| **Rule / Global** | 规则分流模式 / 全局代理模式 | 日常永远选 **Rule**，选 Global 会拖慢国内软件且白耗流量 |
| **TUN 模式** | 虚拟网卡底层接管模式 | 网页浏览器无需开 TUN；终端命令/游戏走代理时才需要开启 |
| **原生 IP / 送中** | IP 注册地归属当前机房 / 被定位回中国 | 送中 IP 看 YouTube 异常，AI 多受限香港机房 |
| **QoS 限速** | 运营商在高峰期对特定跨境连接降速 | 常见表现是白天飞快、晚上八点断崖式下跌 |

## 日常安全守则

- 仅通过官方仓库下载开源客户端；不要点击弹窗广告推荐的神秘“破解永久免费 VPN”。
- 注册账号使用独立密码；涉及重要资金或敏感账号操作时固定常用安全地区节点。
- 遵守所在地相关法律法规，将网络工具用于合规的跨境技术检索、学术研究与日常效率提升。
