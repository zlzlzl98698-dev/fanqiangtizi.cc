## 临时测试未知节点的 4 条安全隔离准则

1. **使用 Chrome 独立访客模式 / 无痕窗口**：确保窗口里没有任何已登录的 Gmail、GitHub、网银或本地 Cookie。
2. **关闭全局同步软件**：测节点前暂时退出 Dropbox/OneDrive/Telegram 桌面客户端，防止背景流量经过该陌生节点。
3. **仅访问无状态纯检测页面**（如 `ipinfo.io`、`speed.cloudflare.com`）。
4. **测试完毕立刻在 Clash 删除该测试节点并恢复常用正规订阅**。
