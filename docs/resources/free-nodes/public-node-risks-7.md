# Cloudflare Workers / 开源自部署方案在轻度个人学习中的合规局限

> **直接结论：** 在开源社区常见有人讨论用 Cloudflare Workers 免费额度自建轻量中转，或买几美元一个月的海外廉价 VPS 自建节点。从学习网络协议角度很有价值，但若指望它“比商业专线机场更快更稳”，现实往往相反。

## 个人买最低配海外 VPS 自建 vs 买专线机场现实对比

1. **线路差距巨大**：几美元的海外入门 VPS 全都是**普通公网直连**，晚高峰电信 163 / 移动出口拥堵照样丢包卡成 PPT；而正规机场用的是采购成本高昂的国内入口 + IEPL 专线。
2. **抗封锁维护精力**：自建 IP 一旦被识别阻断，换 IP 手续繁琐且常收换 IP 费；机场后端有多台冗余中转随时动态替补。
3. **Cloudflare Workers 边界**：免费版 Worker 存在并发限额，且官方严格禁止滥用无服务器计算资源充当通用高流量代理隧道（易直接封停账号）。
