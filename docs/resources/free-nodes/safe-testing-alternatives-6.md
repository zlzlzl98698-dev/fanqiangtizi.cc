# 开源代理工具自身代码安全：学会在 GitHub 查看 Stars、Commit 与 Issues

> **直接结论：** 不会写代码也完全可以在 GitHub 上 30 秒判断一款开源代理软件是不是安全活跃的真官方项目：只需要会看 **Repository 完整作者路径、Stars 数量、最近一次 Commit 更新时间与 Releases 发布页** 四处即可。

## 普通人 30 秒看懂 GitHub 仓库健康度

1. **核对作者用户名与链接**：不要搜到同名 `clash-verge-xx` 别人 Fork 拷贝的假仓库，确认是原始作者组织路径（如 `clash-verge-rev/clash-verge-rev`）。
2. **看 Stars（星标）与 Forks**：成熟主力开源工具通常拥有数千甚至数万 Stars；只有十几颗星的同名新克隆仓库极其可疑。
3. **看 Latest Release 发布时间与 Commits**：观察最近几个月内是否还有代码提交与版本迭代（借此即可一眼识别已归档停更或长期失修的项目）。
