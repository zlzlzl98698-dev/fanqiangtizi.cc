## 多设备个人网络卫生好习惯 5 条

1. **密码绝不复用**：机场注册密码、开源社区密码与国内支付/主力邮箱密码严格做到一平台一密码（推荐搭配密码管理器生成随机强密码）。
2. **敏感账号不碰不明节点**：主力 Gmail、GitHub、银行、交易所仅在干净可靠的主力节点或本地直连下操作。
3. **定期审计本地自启项与浏览器扩展**：移除半年不用的未知插件。
4. **保存重要恢复代码与 2FA 两步验证密钥**。
