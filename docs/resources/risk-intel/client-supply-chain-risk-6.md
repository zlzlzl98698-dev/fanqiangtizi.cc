# Windows 与 macOS 代理软件被要求“关闭杀毒/输入管理员密码”时的判断基准

> **直接结论：** 安装和使用代理客户端过程中，最让新人心里打鼓的瞬间就是弹出“请求管理员权限”或者“Windows 安全中心拦截”。判断究竟是正常驱动行为还是恶意木马，核心看**安装包来源是否经过开源校验**以及**索权发生的具体操作环节**。

## 正常系统索权 vs 可疑恶意行为区分标准

- **合理正常的管理员请求**：仅在你主动点击安装 `setup.exe` 安装程序、或者主动在 Clash Verge Rev 里点击安装「Service Mode（服务模式）/ 开启 TUN 虚拟网卡」时弹出 UAC 请求提权——因为修改系统服务和创建虚拟网卡驱动本来就必须管理员权限。
- **极度可疑的流氓特征**：安装包来自非 GitHub 中文广告站、一运行还没进配置页面就强制要求你彻底关闭 Windows Defender 实时防护、或者静默往系统根目录塞进未知 Root 证书。遇到这种直接彻底删除！
