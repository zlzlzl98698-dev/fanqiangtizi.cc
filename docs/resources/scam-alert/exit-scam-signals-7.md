# 避免同一密码撞库风险：注册机场账户时的独立随机密码规范

> **直接结论：** 小众代理网站的安全防护通常远不如大型科技公司，一旦遭遇脱库，黑客手里拿到的第一批数据就是你的“注册邮箱 + 明文/弱加密密码”。做到密码绝对独立，就能彻底斩断小站泄露向主账号蔓延的通道。

## 10 秒生成安全独立账号密码的方法

- **浏览器自带密码生成器**：在 Chrome/Edge/Safari 或 Bitwarden 中注册时直接右键选择“使用强密码建议”并保存，不同网站自动分配完全不同的 16 位随机混合串。
- **绝对禁止的密码习惯**：不要把“姓名缩写+生日”、“常用银行卡六位”或“全网一套万能密码”输入任何小网站。
