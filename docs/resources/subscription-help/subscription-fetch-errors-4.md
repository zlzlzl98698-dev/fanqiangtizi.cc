# 导入订阅成功但节点列表里只有两条流量提示，没有任何实际可用节点

> **直接结论：** 机场订阅导入时如果并未提示任何格式错误，却只显示寥寥一两条包含流量提示或官网域名的条目，没有任何实际香港/美国节点，99% 是服务端返回了账户异常状态的提示节点。

## “只见提示不见节点” 3 项快速核对

1. **登录机场官网查看仪表盘**：核对是否刚好**已到期**、**总流量已跑满 100%**，或者买的新套餐尚未支付完成激活。
2. **确认是不是用了专属客户端限定套餐**：部分品牌仅保留自研 App 通道，外链订阅可能返回空列表或提醒去下专用客户端。
3. **检查是否不小心误添了极端过滤规则**：排查自己在 Clash 覆写配置里是不是写错了 `filter` 正则表达式，把全部正常节点名一不小心全过滤掉了。
