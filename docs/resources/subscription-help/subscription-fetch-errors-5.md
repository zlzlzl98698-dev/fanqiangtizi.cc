# 机场在后台新增或修复了节点，客户端为什么点击更新后列表没变化

> **直接结论：** 机场公告通知刚刚上线了几个全新高速节点，可你在 Clash Verge Rev 里猛点更新订阅，列表数量和名字却纹丝不动。常见原因包括 CDN 边缘缓存未刷新、远程地址请求超时失败回退了旧缓存，或者配置中开了禁止覆盖。

## 强制让客户端拉取最新节点列表的 3 个动作

1. **观察刷新提示弹窗颜色**：只有顶部弹出绿色 `Success` 才代表真正拉取成功；如果是红色报错，其实是拉取失败后软件为了不断网自动保留了昨天的旧本地缓存！
2. **检查是否开启代理更新**：老订阅域名超时时记得勾选“通过代理更新”再刷新。
3. **最彻底强制刷新**：备份好自定义扩展规则后，在订阅页**删除旧订阅卡片**，从官网后台重新复制一遍订阅 URL（有时面板迁站改了域名参数）再次粘贴导入。
