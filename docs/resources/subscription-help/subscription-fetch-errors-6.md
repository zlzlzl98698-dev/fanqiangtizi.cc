# 浏览器直接打开订阅地址下载了一个 TXT 文件怎么手动导入客户端

> **直接结论：** 极端网络环境下订阅 URL 被客户端直连超时拦截，但你用手机流量或另一台设备在浏览器直接打开该网址却能下载出一个包含节点配置的 TXT / YAML 文本文件——这时候直接把该本地文件拖进 Clash 照样能立刻连上！

## 本地离线配置文件手动导入 Clash Verge Rev

1. 将下载得到的配置文件文本确认内容（若开头有 `proxies:` 字样），将其文件后缀改为 **`.yaml`**（例如 `backup.yaml`）。
2. 打开 Clash Verge Rev「订阅（Profiles）」页。
3. 直接把该 `backup.yaml` 文件**用鼠标拖拽放进软件窗口**（或点击导入按钮旁的本地文件图标选取上传），点击激活即可立马上网！
4. **连上网后再顺手填回官方在线订阅 URL**，方便日后自动同步节点变化。
