# 机场订阅拉取与更新失败排错大全：超时、403、空节点与域名失效修复

> **直接结论：** 更新订阅报错绝大多数并非电脑坏了，而是**本地直连访问订阅域名受阻**、**机场更换了新面板地址**或**订阅服务器拒绝了非标准 User-Agent 请求**。

## 5 种典型订阅报错排查对照表

| 报错提示 / 现象 | 常见根因 | 快速解决操作 |
| --- | --- | --- |
| `TLS handshake timeout` / 连接超时 | 订阅域名在国内直连网络下访问超时 | 先开启任意可用节点，在订阅设置里勾选**“通过代理更新”**再刷新 |
| `HTTP 403 Forbidden` | 机场防火墙拦截了异常请求头或订阅 Token 已重置 | 去官网重新复制最新订阅 URL；在 Clash Verge 中确认未改坏 User-Agent |
| 导入成功但只有“流量提示”无节点 | 套餐过期、流量清零，或订阅格式仅兼容特定客户端 | 登录官网核查套餐余量；确认机场是否已改为“仅限专属客户端” |
| `Invalid YAML` / 格式解析失败 | 复制链接不完整，或链接实际返回了 Base64/网页 | 直接用浏览器打开订阅链接检查内容；若为长串乱码需加 `&flag=clash` |
| 更新后节点名字依然是旧的 | 本地客户端或 CDN 节点缓存尚未刷新 | 右键删除旧订阅记录（备份好自定义覆写后）重新粘贴导入 |
