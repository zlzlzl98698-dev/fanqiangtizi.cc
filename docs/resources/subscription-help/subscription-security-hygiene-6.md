# 机场迁站更换面板后旧订阅 URL 自动失效的平滑更新通知检查

> **直接结论：** 当老机场服务商由于域名到期、风控切换或面板系统升级（如从旧版 SSPanel 迁往新版 V2Board/Xboard）时，原来的老订阅域名往往会跟着作废停止响应。

## 迁站更换面板后的平滑过渡检查

1. **核查官方发信或发布页**：第一时间确认邮箱收到的迁移通知是否来自官方正牌邮箱（警惕仿冒域名诈骗）。
2. **用旧官网或发布页进入新面板重新复制新订阅 URL**：老面板里的 Token 在迁站数据库重建时通常已变更，直接点旧配置刷新往往一直 404 或超时。
3. **在 Clash 删除已停用的旧卡片，重新导入新域名订阅地址**。
