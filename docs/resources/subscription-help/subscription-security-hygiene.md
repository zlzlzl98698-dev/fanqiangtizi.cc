# 订阅链接安全管理与参数规范：多客户端识别、Flag 后缀与防盗刷指南

> **直接结论：** 你的订阅链接等同于**“不需密码直接消耗你账号流量的免密通行证”**。保管订阅链接应像保管银行卡密码一样谨慎：不乱发截图、不贴进陌生第三方网页、发现异常立即后台重置。

## 订阅安全日常检查 4 项习惯

1. **善用后台“重置订阅地址”功能**：一旦换电脑、借给过他人临时使用或误贴进公共网站，第一时间重置订阅。
2. **理解 `&flag=clash` 与 `&flag=shadowrocket`**：如果同一个订阅链接下发格式不对，可在面板复制对应专属按钮链接，或使用各自原生支持的客户端减少中间转换环节。
3. **排查本地后台偷跑流量大户**：在 Clash Verge Rev 的「连接」页面按流量排序，一眼揪出到底是哪个进程在后台持续跑大流量（常见如网盘客户端、Docker、云相册同步、Windows Update）。
4. **切勿直接转交官网登录账密**：即使临时给家人或同事配设备，也只导入订阅配置而不直接共享官网登录密码。
