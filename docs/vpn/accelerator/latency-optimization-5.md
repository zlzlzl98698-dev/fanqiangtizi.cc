# BBR 拥塞控制与现代代理传输协议如何影响跨太平洋美国线路速度

> **直接结论：** 光速在光纤中的传输速度决定了从中国大陆跨过太平洋到达美国西海岸物理往返延迟极限就在 120–140ms 左右。根据带宽延迟积（BDP）规律，高延迟链路上任何轻微丢包都会让普通单线程吞吐剧烈萎缩。

## 为什么香港常跑 500Mbps 而美国常常只有几十 Mbps？

1. **物理 RTT 差 6 倍**：香港往返 ~22ms，美国西海岸 ~145ms。在传统 TCP 协议下，高 RTT 意味着发送端确认拥塞窗口恢复极慢，1% 的丢包就能让美国单线程从 200Mbps 掉到 15Mbps。
2. **BBR 拥塞控制与 VLESS/Hysteria 2 的提速价值**：从光速云 2026-08-19 珠海联通 9Gbps VLESS 专项测速图也能看到，换用现代优化线路与 VLESS 后，美国节点平均速度可冲到 `313–370MB/s`（局部美02异常除外）。

## 美国节点速度慢原因：跨端环境部署与适配清单

在阅读「延迟与抖动调优技巧」专题集群时，围绕核心搜索意图（信息查询）需特别确认 VPN加速器 与具体落地环节是否匹配：从本地网络、DNS 策略、入口挑选与 MUX/TCP 参数角度降低抖动。

- **桌面办公（Windows / macOS / Linux）**：推荐使用开源 **Clash Verge Rev** 或 **FlClash**；Mac 用户需区分 `aarch64` (M1–M4) 与 `x64` (Intel)。
- **移动设备（iOS / Android）**：iOS 首选外区 App Store 正版 **Shadowrocket / Karing / Stash**（切勿在系统 iCloud 登录共享外区号）；Android 首选 **FlClash / v2rayNG** 并关闭电池省电优化。
- **家用网关（OpenWrt 软路由）**：支持通用订阅的机场可写入 **OpenClash / PassWall2 / HomeProxy**，或 OpenWrt 24.10+ 原生的 **Nikki**。
- **选型复核提醒**：若同时考虑传统海外商业 VPN 与国内专线机场，务必结合自身日常需求是否需要精确规则分流（国内外分流）与多地区独立落地 IP。
