# 在桌面端排查本地 Wi-Fi 干扰 vs 代理链路慢的 3 步对照法

> **直接结论：** 网速变慢时不要急着骂机场或换套餐，先用 30 秒做一次“本地直连测速 → 客户端连接日志 → 换同机场他区节点”三步对照法，能瞬间分清到底是谁的锅。

## 3 步快速故障归因法

1. **测本地直连基准**：把 Clash 切到 `Direct` 直连，用国内测速软件测自家 Wi-Fi 延迟和丢包。如果连到自家路由器的延迟都飙到 60ms 以上（典型 2.4G Wi-Fi 干扰或家里有人挂满下载），换再贵专线也卡。
2. **对比同一机场不同地区节点**：如果香港01卡死但新加坡01飞快，说明只是单一香港落地或单条入口临时拥堵，切节点即可。
3. **测试另一家备用机场**：若全部节点均大面积慢，再检查本地运营商晚高峰国际出口波动。

## 排查本地网络还是机场慢：跨端环境部署与适配清单

在阅读「延迟与抖动调优技巧」专题集群时，围绕核心搜索意图（故障排查）需特别确认 VPN加速器 与具体落地环节是否匹配：从本地网络、DNS 策略、入口挑选与 MUX/TCP 参数角度降低抖动。

- **桌面办公（Windows / macOS / Linux）**：推荐使用开源 **Clash Verge Rev** 或 **FlClash**；Mac 用户需区分 `aarch64` (M1–M4) 与 `x64` (Intel)。
- **移动设备（iOS / Android）**：iOS 首选外区 App Store 正版 **Shadowrocket / Karing / Stash**（切勿在系统 iCloud 登录共享外区号）；Android 首选 **FlClash / v2rayNG** 并关闭电池省电优化。
- **家用网关（OpenWrt 软路由）**：支持通用订阅的机场可写入 **OpenClash / PassWall2 / HomeProxy**，或 OpenWrt 24.10+ 原生的 **Nikki**。
- **选型复核提醒**：若同时考虑传统海外商业 VPN 与国内专线机场，务必结合自身日常需求是否需要精确规则分流（国内外分流）与多地区独立落地 IP。
