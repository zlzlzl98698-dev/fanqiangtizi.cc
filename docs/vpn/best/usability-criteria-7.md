# 告别频繁换节点：如何设定稳定的日常默认策略组

> **直接结论：** 天天盯着客户端看哪个节点低了 5ms 非常消耗精力。正确做法是经过 2 天验证后，在「日常 Proxy 组」选定一个最稳的香港/新加坡主力节点（或使用 tolerance 较大的 fallback 组），从此不再手动切节点。

## 省心日常默认策略组设置规范

- **把自动化和人工固定结合**：
  - 将 **`select`（手动选择）** 放在日常最核心分组，固定在本地测试连续两天极稳的 `香港专线03`（示例）；
  - 或者利用 **`fallback`** 按顺位排好 `香港03 -> 香港05 -> 新加坡01`，既不会每隔 3 分钟跳一次 IP，又能在单台服务器重启维护时自动顶上；
  - 把 **OpenAI / Gemini** 通过分流规则单独锁死在 `新加坡/美国` 分组，从此开电脑永远零操作。

## Clash默认策略组设置：跨端环境部署与适配清单

在阅读「真正好用的五大体验标准」专题集群时，围绕核心搜索意图（操作教程）需特别确认 好用的VPN 与具体落地环节是否匹配：不吹嘘跑分，聚焦一键连接、自动选优、客服响应与多端无缝接续。

- **桌面办公（Windows / macOS / Linux）**：推荐使用开源 **Clash Verge Rev** 或 **FlClash**；Mac 用户需区分 `aarch64` (M1–M4) 与 `x64` (Intel)。
- **移动设备（iOS / Android）**：iOS 首选外区 App Store 正版 **Shadowrocket / Karing / Stash**（切勿在系统 iCloud 登录共享外区号）；Android 首选 **FlClash / v2rayNG** 并关闭电池省电优化。
- **家用网关（OpenWrt 软路由）**：支持通用订阅的机场可写入 **OpenClash / PassWall2 / HomeProxy**，或 OpenWrt 24.10+ 原生的 **Nikki**。
- **选型复核提醒**：若同时考虑传统海外商业 VPN 与国内专线机场，务必结合自身日常需求是否需要精确规则分流（国内外分流）与多地区独立落地 IP。
