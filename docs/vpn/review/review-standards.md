# 翻墙梯子评测方法论：我们如何区分实测截图、三网数据与厂商宣称

> **直接结论：** 一篇合格的网络服务评测不能只由“跑分最高的一张截图 + 复制粘贴的官网卖点”组成。**把测试日期、测试后端运营商、协议与失败样本全部透明摊开**，才具备长期决策参考价值。

## 本站四大证据标签说明

| 标签 | 对应展示样式 | 审核要求 |
| --- | --- | --- |
| `Measured Data` | 绿色状态标签 | 必须具有原始测试图（如 MAI-TEST-BOT 或 MiaoKo 截图），标注精确测试时间与后端环境。 |
| `Vendor / List Data` | 琥珀色状态标签 | 来自品牌页面或统一文字清单描述，严禁在正文中改写为“经本站实测”。 |
| `Historical` | 灰色警示标签 | 2026-08-09 历史库留档，价格与入口有效期必须提示二次核实。 |
| `Not Tested` | 灰色空值标签 | 缺乏测试数据一律填“—”或“待核实”，拒绝利用脚本批量伪造假数据。 |

## VPN怎么评测：跨端环境部署与适配清单

在阅读「透明评测标准与证据分级」专题集群时，围绕核心搜索意图（信息查询）需特别确认 VPN软件评测 与具体落地环节是否匹配：阐明本站如何区分独立测速截图、三网测速、厂商宣称与待核实信息。

- **桌面办公（Windows / macOS / Linux）**：推荐使用开源 **Clash Verge Rev** 或 **FlClash**；Mac 用户需区分 `aarch64` (M1–M4) 与 `x64` (Intel)。
- **移动设备（iOS / Android）**：iOS 首选外区 App Store 正版 **Shadowrocket / Karing / Stash**（切勿在系统 iCloud 登录共享外区号）；Android 首选 **FlClash / v2rayNG** 并关闭电池省电优化。
- **家用网关（OpenWrt 软路由）**：支持通用订阅的机场可写入 **OpenClash / PassWall2 / HomeProxy**，或 OpenWrt 24.10+ 原生的 **Nikki**。
- **选型复核提醒**：若同时考虑传统海外商业 VPN 与国内专线机场，务必结合自身日常需求是否需要精确规则分流（国内外分流）与多地区独立落地 IP。
